## 第一优先级：Java基础（必须背）

```
1. HashMap底层原理（数组+链表+红黑树）
2. HashMap和HashTable的区别
3. ArrayList和LinkedList的区别
4. String、StringBuilder、StringBuffer的区别
5. ==和equals的区别
6. Java泛型是什么，为什么要用
7. 接口和抽象类的区别
8. final关键字的作用
9. Java异常体系（Checked/Unchecked）
10. 重载和重写的区别
```

## 第三优先级：MySQL（必问）

```
1. 索引是什么，为什么用B+树
2. 聚簇索引和非聚簇索引的区别
3. 事务的ACID特性
4. 事务隔离级别（4个）
5. MySQL有哪些锁（行锁、表锁、间隙锁）
6. LEFT JOIN和INNER JOIN的区别
7. SQL优化的方法（explain、加索引、避免select *）
```
