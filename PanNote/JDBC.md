### JDBC 连接 URL 的构成

一个典型的 MySQL 连接地址看起来像这样： `jdbc:mysql://localhost:3306/databasename`

我们可以把它拆解为三个部分：

1. **协议 (jdbc)**：告诉程序我们要使用 JDBC 标准。
    
2. **子协议 (mysql)**：指定具体的数据库供应商。
    
3. **地址和端口 (localhost:3306)**：数据库在网络中的具体位置（localhost 代表本机，3306 是数据库默认的“大门”编号）。
    
4. **资源名 (databasename)**：你要访问的具体数据库文件夹。

| **代码关键点**                | **生活类比** | **核心逻辑点**                                                                          |
| ------------------------ | -------- | ---------------------------------------------------------------------------------- |
| **Connection URL**       | 拨号地址     | 包含协议、数据库类型、IP端口和资源名。                                                               |
| **Statement**            | 搬运工      | 只负责搬运，它并不理解 SQL 的具体逻辑                                                              |
| **PreparedStatement**    | 专业押运员    | 负责搬运 SQL，通过 `?` 占位符防止 SQL 注入。                                                      |
| **ResultSet**            | 电子表格     | 初始光标在第一行之前，需用 `.next()` 移动。                                                        |
| **ResultSet.next()**     | 探测器      | - 返回 `true`：光标成功指向了有效的数据行，你可以开始读取这一行里的内容了。<br>- 返回 `false`：说明已经到达了表格的最末端，循环就会自然停止。 |
| **setAutoCommit(false)** | 开启草稿模式   | 所有的更改都不会立即生效，直到你确认。                                                                |
| **commit / rollback**    | 确认 / 撤销  | 事务的终点，决定数据是永久保存还是重置。                                                               |
| **close()**              | 挂断电话     | 必须执行的操作，否则会导致运行内存爆炸。                                                               |
JDBC 的全套逻辑：

1. **加载驱动**：准备翻译官。
    
2. **获取连接**：拨通电话（需要 URL 路径）。
    
3. **创建执行器**：雇佣搬运工（`Statement` 或更安全的 `PreparedStatement`）。
    
4. **执行并获取结果**：发送指令，得到电子表格（`ResultSet`）。
    
5. **遍历与转换**：移动光标，将数据翻译回 Java 变量。
    
6. **关闭资源**：挂断电话，释放内存


# JDBC的万能模板：
JDBC 执行逻辑框架：
```
// JDBC 核心逻辑框架
public class JdbcTemplate {
    public void execute() {
        // 1. 注册驱动：告诉 Java 我们要和哪个供应商说话
        // 2. 获取连接：通过 URL、用户名、密码建立物理通道
        // 3. 创建执行器：准备一个承载 SQL 指令的“信封”
        // 4. 发送 SQL 并获取结果：把信发出去，并拿到回信
        // 5. 遍历结果：拆开回信，读取数据
        // 6. 释放资源：关闭通道，防止浪费内存
    }
}
```

批处理逻辑框架：
```
// 1. 准备搬运工
try (PreparedStatement pstmt = conn.prepareStatement(sql)) {
    for (Data data : dataList) {
        // 2. 填空
        pstmt.setXXX(1, data.getValue());
        // 3. 塞进箱子，但不发送
        pstmt.addBatch();
    }
    // 4. 统一寄出，返回一个包含每条指令影响行数的数组
    int[] results = pstmt.executeBatch();
}
```

异常捕获与诊断：
```
try {
    // JDBC 操作代码
} catch (SQLException e) {
    // 1. 获取错误描述：到底发生了什么？
    // 2. 获取错误状态码：数据库供应商提供的标准代码
    // 3. 获取供应商特定的错误码：更具体的内部编号
}
```
