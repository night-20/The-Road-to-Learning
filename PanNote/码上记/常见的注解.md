| 注解                          | 作用                       | 记忆方法                       |
| --------------------------- | ------------------------ | -------------------------- |
| `@RestController`           | 标记这是一个接口类，方法返回值直接作为响应体   | Rest = 接口，Controller = 控制器 |
| `@RequestMapping("/hello")` | 给整个类定义 URL 前缀            | Mapping = 映射               |
| `@GetMapping`               | 处理 GET 请求（浏览器直接访问就是 GET） | Get = 获取数据                 |
| `@PathVariable`             | 从 URL 路径里取参数             | Path = 路径，Variable = 变量    |

|注解|作用|
|---|---|
|`@PostMapping`|处理 POST 请求|
|`@RequestBody`|把请求体里的 JSON 自动转成 Java 对象|

> 💡 **记住这个规律：**
> - 从 URL 取参数 → `@PathVariable`
> - 从请求体取 JSON → `@RequestBody`



#### 理解 Spring Boot 的启动原理

打开 `MemosAppApplication.java`，你会看到：

java

```java
@SpringBootApplication
public class MemosAppApplication {
    public static void main(String[] args) {
        SpringApplication.run(MemosAppApplication.class, args);
    }
}
```

这 3 行代码背后做了什么：

```
main() 执行
    ↓
SpringApplication.run() 启动
    ↓
① 扫描所有 @RestController / @Service 等注解的类，注册进容器
② 读取 application.yml，连接数据库
③ 启动内嵌的 Tomcat 服务器，监听 8080 端口
    ↓
项目启动完成，开始接收请求
```

> 💡 `@SpringBootApplication` 是个组合注解，相当于同时加了 3 个注解，你现在不用深究，记住"它让 Spring Boot 跑起来"就够了。
