# 本次开发问题总结

## 1. application.yml 配置格式错误
**问题**：第一行使用了 properties 格式 `spring.application.name=20260505`，与 YAML 格式混用。
**解决**：改为 YAML 层级格式：
```yaml
spring:
  application:
    name: 20260505
```

## 2. 缺少 package 声明和 import
**问题**：UserMapper、UserController、User 等文件缺少 `package` 声明和必要的 `import` 语句。
**解决**：补充完整的 package 和 import。

## 3. MyBatis 与 MyBatis-Plus 依赖冲突
**问题**：同时引入了 `mybatis-spring-boot-starter`（原生 MyBatis）和 `mybatis-plus-boot-starter`，导致 `Invalid bound statement (not found): selectList` 错误。
**原因**：原生 MyBatis 不认识 MyBatis-Plus 的 `BaseMapper` 中的方法。
**解决**：移除 `mybatis-spring-boot-starter`，只保留 MyBatis-Plus。

## 4. MyBatis-Plus 版本与 Spring Boot 4 不兼容
**问题**：`mybatis-plus-boot-starter:3.5.5` 与 Spring Boot 4.0.6 不兼容，报错 `Invalid value type for attribute 'factoryBeanObjectType'`。
**解决**：改用 Spring Boot 4 专用 starter `mybatis-plus-spring-boot4-starter`。

## 5. MyBatis-Plus 版本不存在
**问题**：版本 3.5.9、3.5.7 在 Maven 仓库中不存在，下载失败。
**解决**：根据官方文档，Spring Boot 4 对应版本为 3.5.15。

## 6. SqlSessionFactory 未自动配置
**问题**：启动报错 `Property 'sqlSessionFactory' or 'sqlSessionTemplate' are required`。
**原因**：MyBatis-Plus 3.5.15 对 Spring Boot 4 的自动配置可能还不完善。
**解决**：创建 `MybatisPlusConfig` 配置类，手动配置 `SqlSessionFactory` 和 `SqlSessionTemplate`。

## 7. PaginationInnerInterceptor 类找不到
**问题**：编译报错 `找不到符号: 类 PaginationInnerInterceptor`。
**原因**：MyBatis-Plus 3.5.15 的包结构可能与之前版本不同。
**解决**：暂时移除分页插件配置，仅保留基础的 SqlSessionFactory 配置。

## 最终解决方案
创建 `MybatisPlusConfig` 配置类，手动配置数据源和 SqlSessionFactory，确保 MyBatis-Plus 能够正常工作。
